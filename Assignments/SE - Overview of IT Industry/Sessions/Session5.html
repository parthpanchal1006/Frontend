1. Git Commands

  1. Initialize a repository: 
    git init
  2. Stage all files: 
    git add .
  3. Commit with a message: 
    git commit -m "Initial commit"
  4. Push to remote: 
    git push origin main
  5. Pull latest changes: 
    git pull origin main

2. Difference Between Git Fetch and Git Pull

Git Fetch: Downloads changes from the remote repository without merging them into the current branch.

Git Pull: Downloads changes and integrates them into the current branch.

3. Create a GitHub Repository and Push a File

  1. Open GitHub and create a new repository.
  2. Create a text file named hello.txt on your computer.
  3. Open the terminal in that folder and run:
git init
git add hello.txt
git commit -m "Add hello text file"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main

Replace YOUR_REPOSITORY_URL with your actual GitHub repository URL.

Repository link: Add your GitHub repository URL here after successfully pushing the file.

4. Difference Between Fork and Pull Request

Fork: Creates your own copy of another user's repository on GitHub.

Pull Request: Requests that your changes be reviewed and merged into another branch or repository.
