1. Five IT Job Roles

  1. Web Developer: Creates and maintains websites.
  2. Software Developer: Develops software applications.
  3. Data Analyst: Analyzes data to find useful information.
  4. Software Tester: Tests software to find bugs.
  5. UI/UX Designer: Designs user-friendly interfaces.

2. Product and Service Companies

Product Companies

  1. Microsoft - Develops Windows and Microsoft Office.
  2. Google - Develops Google Search and Gmail.
  3. Adobe - Develops Photoshop and Acrobat.

Service Companies

  1. TCS - Provides IT consulting services.
  2. Infosys - Provides software development services.
  3. Wipro - Provides IT and cloud services.

3. Full Forms and Uses

Term Full Form Use

4. Five Programming Languages

  1. Python - AI and data analysis.
  2. Java - Enterprise software development.
  3. JavaScript - Interactive websites.
  4. PHP - Server-side web development.
  5. C++ - Game and system development.

5. Difference Between Developer and Tester

Developer: Writes code and builds software applications.

Tester: Tests software to find bugs and check functionality.
