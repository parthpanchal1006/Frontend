1. Three Main Layers of Software Architecture

  1. Presentation Layer: Displays information to the user.
  2. Business Logic Layer: Processes data and applies application rules.
  3. Data Layer: Stores and retrieves data from the database.

2. Client and Server

Client: A device or application that requests a service.

Server: A computer or program that processes requests and provides responses.

Example: When you open Google in a browser, the browser is the client and Google's server sends the search results.

3. Differences Between Desktop, Web, and Mobile Apps

Application Difference 1 Difference 2
Desktop App Installed on a computer. Designed mainly for Windows, macOS, or Linux.
Web App Accessed through a web browser. Usually works across devices without separate installation.
Mobile App Designed mainly for smartphones and tablets. Can use mobile features like GPS and the camera.

4. Three Databases and Their Types

  1. MySQL: SQL database.
  2. PostgreSQL: SQL database.
  3. MongoDB: NoSQL database.
