1. Full Forms and Uses

  1. HTTP: Hypertext Transfer Protocol - Transfers data between a web browser and a web server.
  2. HTTPS: Hypertext Transfer Protocol Secure - Transfers data securely using encryption.
  3. FTP: File Transfer Protocol - Transfers files between computers over a network.
  4. SMTP: Simple Mail Transfer Protocol - Sends emails between mail servers.

2. Difference Between IPv4 and IPv6

IPv4 uses 32-bit addresses, such as 192.168.1.1.

IPv6 uses 128-bit addresses, such as 2001:db8::1, and supports a much larger number of addresses.

3. Find the IP Address of Google

Open Command Prompt on Windows and run this command:

nslookup google.com

Write down the IP address shown in the output. The address may vary depending on your network and DNS server.

4. HTTP Status Codes

  • 200: OK - The request was successful.
  • 301: Moved Permanently - The resource has a new permanent URL.
  • 404: Not Found - The requested resource was not found.
  • 500: Internal Server Error - The server encountered an unexpected error.
  • 403: Forbidden - The server refuses to allow access.

5. DNS Hierarchy

Example: www.google.com

  1. Root: The top level of DNS, represented by a dot (.).
  2. TLD: .com is the Top-Level Domain.
  3. Domain: google is the registered domain name.
  4. Subdomain: www is the subdomain of google.com.
